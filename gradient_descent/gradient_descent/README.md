# Gradient Descent Assignment
This assignment implements linear regression using gradient descent.

## Dataset
UCI Real Estate Valuation Dataset (ID = 477).

## Workflow
1. Load the real estate dataset.
2. Split dataset into training set (80%) and test set (20%).
3. Standardize features.
4. Implement gradient descent algorithm for linear regression.
5. Evaluate model performance on unseen test data with MSE and RMSE.

## Result
Training loss: 41.5567
Test MSE: 53.5056
Test RMSE: 7.3148
